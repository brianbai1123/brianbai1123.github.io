# 原则、思想、知与行

**https://brianbai1123.github.io/**

六本书读下来反复出现的十二条原则：至少三本书各自独立说过，才算一条。每条按五步讲——先理解、核心观点、重建逻辑、简单表达、检查——并附上能点回原书页面的佐证。只有两本书支持的放在「还在观察的候选」里。

页面最后是参考列表，六本书仍发布在原来的路径上：

- 导读：七个习惯、原则、进化心理学
- 经文卡片：孙子兵法、周易
- 索引：历久

六本书的每一页都会加载 `public/reading-room.js`：左下角的按钮回到这里；读过的位置记在这台浏览器里；相关章节底下会多一行「这条在别处」。

原则的内容在 `src/content/principles.ts`。
